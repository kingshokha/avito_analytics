# 🚀 Авито Аналитика (Avito Analytics Pro Dashboard)

Профессиональный интерактивный веб-дашборд для визуализации и отслеживания эффективности объявлений, расходов на продвижение, конверсии лидов (звонки и чаты), показов, просмотров, работы мессенджера (CRM) и отслеживания заказов **Авито Доставки** через официальный **Avito API**.

![Avito Analytics Dashboard Preview](https://images.unsplash.com/photo-1551288049-bebda4e38f71?w=1200&auto=format&fit=crop&q=80)

---

## ✨ Основные Возможности

- 💬 **Мессенджер и Чат-бот (Avito Messenger CRM)** *(НОВОЕ!)*:
  - Просмотр диалогов с покупателями через `GET /messenger/v2/accounts/{user_id}/chats`.
  - **Быстрые шаблоны автоответов в 1 клик**:
    - ⚡ *«Товар в наличии, готовы оформить?»*
    - 🚚 *«Отправлю сегодня Авито Доставкой!»*
    - 📍 *«Адрес самовывоза: ул. Ленина 15 (с 10:00 до 20:00)»*
    - 💰 *«Сделаю скидку 5% при заказе прямо сейчас!»*
  - Фильтрация непрочитанных сообщений и поиск по покупателю/товару.

- 🚚 **Авито Доставка и Логистика (Order & Delivery Tracker)** *(НОВОЕ!)*:
  - Мониторинг статусов отправлений: *В пути*, *Ожидает в пункте выдачи*, *Завершен и Выплачен*.
  - Аналитика служб доставки (СДЭК, Почта России, Boxberry, Avito Exmail, Яндекс Доставка).
  - Расчет удержанных комиссий Авито и итоговой суммы к выплате на карту.

- 📊 **Ключевые показатели (KPIs)**:
  - 📺 **Показы (Impressions)** — количество показов карточек объявлений в выдаче и поиске Авито.
  - 👁 **Просмотры (Views)** — количество уникальных кликов и переходов внутрь объявлений.
  - 📞 **Контакты / Лиды (Contacts)** — клики «Показать телефон» и чаты.
  - ❤️ **В Избранное (Favorites)** — сохранения объявлений пользователями.
  - 📈 **CTR (%)** — соотношение конверсии просмотров и показов.
  - 💰 **Затраты (Spend / ₽)** — фактический расход средств на продвижение (X2, X5, X10, XL, Выделение цветом).
  - 🎯 **CPL & ROI (%)** — стоимость за лид и процент окупаемости.

- 📈 **Интерактивные графики (Recharts)**:
  - **Динамика метрик по дням** с переключаемыми галочками для каждой метрики (Показы, Просмотры, Контакты, Избранное, CTR, Затраты).
  - **Хронологическая сортировка** дат (от старых к новым).
  - **Круговая диаграмма распределения бюджета** по типам услуг продвижения.

- 🔍 **Автоматическое сканирование (Auto-Discovery Pipeline)**:
  - Автоматическое выявление объявлений из личного кабинета через `GET /core/v1/items`.
  - Извлечение объявлений из отчетов автозагрузки (`GET /autoload/v1/accounts/.../reports/last_report/`).
  - Многостраничный поиск (Pages 1–5) по всем статусам (`active`, `old`, `rejected`).

## 🛠 Технологический Стек

- **Core**: React 18, HTML5, JavaScript (ESNext)
- **Сборщик & Dev Server**: Vite 5 (с настроенным CORS Proxy `/avito-api` -> `https://api.avito.ru`)
- **Графики**: Recharts (AreaChart, PieChart, ResponsiveContainer)
- **Иконки**: Lucide React
- **Стили**: Vanilla CSS3, **Dark Glassmorphism** (стекломорфизм, фирменный мятный цвет `#00aa8e`, анимации)

## 🚀 Быстрый Запуск

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/kingshokha/avito_analytics.git
cd avito_analytics
npm install
```

### 2. Запуск сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу: **http://localhost:3000/**

### 3. Сборка для Production
```bash
npm run build
```
